# 玄易点麦 · 麦当劳卦象决策 Skill

> 「玄易决策官 × 麦当劳 MCP 点餐决策」—— 用《易经》卦象的趣味意象，结合麦当劳 MCP 真实菜单与价格，帮你轻松决定"今天吃什么麦当劳"。

## 一、简介

"今天吃什么"是当代人的日常决策疲劳。**玄易点麦**把这份疲劳转化为一次轻量的卦象推演：依你的处境（饥饿度 / 时令体质 / 场景 / 心愿 / 日期）配一卦，再叠加麦当劳 MCP 拉取的**真实在售菜单**与**实时价格**，给出轻食方案，并附一句心愿彩头增添趣味。

项目定位为**趣味决策参考，不构成营养 / 医疗 / 专业建议**；默认只读推荐，**不自动下单**。

## 二、核心特性

- **卦象配餐**：处境 → 配卦（颐卦·小颐 / 节卦·节制 / 损卦·减欲 / 既济·小犒赏），给出饮食宜忌。
- **真实菜单**：通过 `mcd-mcp` 拉取门店在售餐品（`productCode`），不做凭空编造。
- **心愿彩头**：求职 / 考试 / 升职 / 脱单 等心愿轴，映射到贴合麦当劳品类的好彩头（如 板烧鸡腿堡=金榜题名、麦香鱼=鱼跃龙门）；若当日恰逢生日 / 纪念日等特殊日期，还会叠加专属彩头并附彩蛋吉祥话。
- **节制 · 天时调制**：以“八分饱、不浪费"为**常驻健康基线**；技能会结合**当前时令**（数据驱动 `hexagrams.json` 的 `solar_terms`：春生 / 夏暑 / 秋燥 / 冬寒）自动强化对应禁忌（秋燥润燥忌冰辛、夏暑清润忌贪凉），使推荐始终贴合当下天时语境。

## 三、安装步骤

1. **申请麦当劳 MCP Token**：前往麦当劳 MCP 开发者平台申请你的 `MCD_TOKEN`（真实 Token 由你本人保管，不入库）。
2. **配置 mcd-mcp 连接器**：在你的 WorkBuddy / MCP 客户端中接入 `mcd-mcp`（详见 `MCP_INTEGRATION.md` 与 `mcp-config.example.json`）。
3. **放入 Skill 目录**：将本目录（`mcd-divination-skill/`）整体放入 WorkBuddy 的 skills 目录，或作为自定义连接器加载。
4. **配置环境变量**：复制 `mcp-config.example.json` 为你的 MCP 配置，并将真实 Token 注入环境变量 `MCD_TOKEN`（**仅占位符，仓库不含真实凭证**）。

## 四、使用示例

**触发词**：玄易麦门官 / `用易经点麦当劳` / `麦门养生点餐` / `今天吃什么麦当劳`

**示例对话（常规定位）**：

> 用户：玄易麦门官，我在公司，不怎么饿，最近秋燥，正在求职。  
> 玄易点麦：今日寒露后属「秋燥」，先以此**天时**轴调制——宜温润润燥、忌冰辛。为你配得【颐卦·小颐】——饮食养正、节饮食。宜温润清淡、七分饱、非辣非油炸、润燥；忌辣、油腻、冰饮、超量套餐。  
> 结合求职心愿，彩头推荐：板烧鸡腿堡 / 麦香鱼（金榜题名 / 鱼跃龙门）。  
> 已从门店在售菜单筛出 A/B 两套温润轻食方案，实时算价后回显（单位已转元）。默认只读推荐，如需下单请前往麦当劳官方 App / 小程序。  
> （趣味决策参考，不构成专业建议）

**示例对话（特殊日期 · 生日彩蛋）**：

> 用户：玄易麦门官，今天 07-20 帮我点个晚饭。  
> 玄易点麦：今日 07-20 恰逢「生日」，先以此**天时**轴调制——夏暑宜清润常温、忌贪凉油腻；叠加生日心愿彩头「又长一岁·诸事顺遂」。为你配得【节卦·节制】——节制守中、量入为出。宜性价比单点、控预算、清润常温；忌超量套餐、贪凉冰饮、油腻燥热。  
> 彩蛋吉祥话：岁岁平安添福寿，年年有余乐无忧。  
> （趣味决策参考，不构成专业建议；输出全程不出现"谐音"二字）

命令行直接试用引擎（不依赖 MCP）：

```bash
python xuanyi_engine.py --date 07-20 --hunger normal
python xuanyi_engine.py --hunger high --wish exam --json
```

## 五、目标用户

- 每天为"吃什么"纠结、想少做决策的麦当劳常客。
- 关注时令养生 / 节制饮食、又喜欢一点文化趣味梗的用户。
- 想用 MCP 真实菜单与价格做趣味决策体验的开发者 / 参赛者。

## 六、合规声明

- 本项目为麦当劳程序员节创意开发大赛参赛作品，由参赛者独立开发，**非麦当劳官方产品**。
- 输出仅供参考，**不构成医疗、营养或其他专业建议**；餐品信息、价格及供应状态以麦当劳官方渠道实时结果为准。
- 文案不含迷信、疗效夸大、浪费引导或贬低品牌内容；以趣味决策参考为定位。
- 写操作（下单 / 领券）默认关闭，仅引导官方渠道；全仓库不含任何真实 Token / 密钥 / 账号。
